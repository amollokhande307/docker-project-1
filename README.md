# Git + Docker Deployment Workflow

##  Workflow

Code Change → Git Commit → Docker Build → Container Run

##  Steps

1. Create application
2. Track using Git
3. Build Docker image
4. Deploy container
5. Update code and redeploy

##  Versions

- v1 → Initial deployment
- v2 → Updated application

##  Key Learning

Git manages code versions  
Docker ensures consistent deployment
